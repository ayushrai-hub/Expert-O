# Expert-O

> A collective of polymaths who design, build, and ship work that has to hold up in the real world.

**Live:** [https://expert-o.vercel.app](https://expert-o.vercel.app)  
**Source:** [github.com/ayushrai-hub/Expert-O](https://github.com/ayushrai-hub/Expert-O)

## What this is

A public marketing site: story, operating pillars, capabilities, engagement shapes, discovery-led pricing, and mailto contact/join forms.

There is **no sign-in or dashboard** on the production site.

## Stack

- React 18, TypeScript, Vite, Tailwind CSS
- Vercel Analytics + Speed Insights
- Deployed as a static SPA on Vercel

## Local development

```bash
git clone https://github.com/ayushrai-hub/Expert-O.git
cd Expert-O
npm install
npm run dev          # http://localhost:5173
```

```bash
npm run build
npm run preview
npm test
npm run type-check
```
